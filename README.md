# Calidad del Agua y Potabilidad

Este repositorio contiene el desarrollo de una práctica ambiental colaborativa
que analiza la calidad del agua y su potabilidad usando herramientas de análisis de datos e IA.

## Estructura del repositorio
- `notebook.ipynb`: Desarrollo principal del análisis.
- `data/`: Archivos de entrada (CSV, Excel, etc.)
- `README.md`: Información general del proyecto.
